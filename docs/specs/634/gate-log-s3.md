## Findings from the live runs

- **The credential proxy is transparent on :80 too.** Run 1 had a TCP connect to `httpbin.org:80`, and to a peer cell's `:80`, succeed in 0–15 ms despite the `{deny, ports:[80]}` rule. A real HTTP request to the same targets times out, so the rule holds for traffic; only the TCP handshake is answered locally. Every :80 check is now an HTTP request, as :443 already was.
- **`httpbin.org/bearer` echoes the injected token into the guest's response** (`bodyHasMarker: true`). The vault keeps the secret out of the guest's environment, not out of what an allowed upstream sends back. A real broker host must not reflect the bearer.
- **The dind image has no `nft` binary**, so the survivor snapshot compares `iptables-save` (counters stripped) instead; per-cell sidecar rules live in the cell's netns, which the netns count covers.
- **A synchronous spawn of `up.sh` starves vitest's worker RPC** ("Timeout calling onTaskUpdate", exit 1 with 8/8 passing). The bring-up and teardown are spawned asynchronously.
- **An empty iptables `raw` table appears once a cell has run** (kernel loads it on first use; default chains, no rules). The netfilter snapshot compares rules and user chains only.
- **Docker Hub drops anonymous blob downloads now and then** (run 6: `EOF` on a server layer; the suite failed in `beforeAll`, no evidence). `up.sh` retries each pull three times.

## Refinement (before roborev)

Fixed: evidence only when every `it` passed and every required check ran; stale evidence removed, written atomically 0600; `blocked` accepts network error kinds only (a probe crash never counts); the guest gateway is asserted before it is probed; peer and metadata checks pass on a network error only; the host scan asserts the workload and sidecar were found and its inputs were non-empty; the guest scan asserts pid 1 and other pids were read; snapshot listings fail loudly instead of returning empty; a run-wide baseline; `denied_dns_nxdomain` requires `gaierror`; the non-discriminating model 401 moved to notes; `platformSha` marks a dirty tree; `artifactDigest` is `sha256:`-prefixed; the API key reaches the config template through the environment, not `sed`'s argv.

## /simplify
