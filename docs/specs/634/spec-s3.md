## Decisions (owner, 2026-11-16)

- **Scope.** AC-3, AC-5, AC-6 and AC-8, the live-API checks listed below, and the conformance evidence for the OpenSandbox runc profile. AC-7 (reconciler) is S4. The rootless re-check on an x86_64 box (IPv6 DNS redirect, rootlesskit AppArmor) moves to S5, which wires that daemon on the box.
- **AC-5's "the guest's model call gets 401".** With a fake token, `api.anthropic.com` answers 401 before and after revoke, so it cannot discriminate. The harness proves revoke with spike 058's method instead: a vault-injected bearer on `httpbin.org/bearer` is 200 before revoke and 401 after. It also records that `api.anthropic.com/v1/models` is 401 after revoke. The PR states this as a deviation from AC-5's wording.
- Earlier ODs stand: OD-2 (upstream BOM images by digest), OD-4 (dind in the harness, no host socket).
- **Validate cycle 1 (BLOCK → fixed here):** evidence shaped for the guard and `cell.rego`; no `expiresAt` (a generated column); TLS/HTTPS probes on :443 because the credential proxy accepts every :443 TCP flow; a contract-true self-check; an encoded canary; a scoped `up.sh` check; exact policies per scenario; a decided 101-rule outcome; metadata and peer probes.

## Contract

### Layout

- `packages/sandbox/opensandbox-it/up.sh`, `down.sh`, `config.toml`: bring-up and teardown ported from spike 058, renamed (`osbit-dind`, label `osbit=1`, API on `127.0.0.1:18091`). Digests pinned in `up.sh`, each commented with its tag: `docker:29.0.1-dind@sha256:ecac43e7…`, `opensandbox/server|execd|egress` at the `release-1.2.1` BOM digests, `python:3.12-slim@sha256:5e2bdb1b…`. The outer `docker run` of `osbit-dind` sits in its own function `run_dind` and carries only `--privileged`, `--name`, `--label`, `-p 127.0.0.1:18091:8090` and `-e DOCKER_TLS_CERTDIR=`. The inner server container gets dind's own socket (`-v /var/run/docker.sock:…` inside dind is expected). Empty `DOCKER_CONFIG`. The API key is generated per run under `umask 077` into `$OPENSANDBOX_IT_STATE/api_key` (default `$TMPDIR/osbit`), never echoed, no `set -x`.
- `packages/sandbox/src/providers/opensandbox-it/up-script.test.ts`: reads `up.sh`, extracts `run_dind`, and refuses `-v`, `--volume`, `--mount`, `--env-file`, a bare `-e NAME` and `docker.sock` in it; refuses `set -x` anywhere. Runs in the normal suite.
- `packages/sandbox/src/providers/opensandbox-it/harness.ts` (test-only helpers):
  - `dind(argv)`: `execFile("docker", ["exec","osbit-dind",...argv])`, argv only.
  - `rawApi(method, path, body?)`: for the negative control, which the adapter refuses by design (`policy_required`).
  - `snapshot()`: containers, volumes, networks, `/var/run/docker/netns` entries and `nft list tables` lines inside dind; `settledSnapshot(expected, deadlineMs)` polls until equal or the deadline.
  - `probeArgv(probes)`: `["python3","-c",PROBE_PY,json]`. Probe kinds: `dns`, `tcp` (only for :80, :853 and peer/metadata IPs), `tls_ip` (TLS to an IP with an SNI), `https` (returns `{status}` and `bodyHasMarker` against an encoded marker, never the body), `canary_scan` (reads `/proc/*/environ` and `/proc/*/cmdline`, decodes the base64 canary from argv inside the probe, returns booleans only).
  - `scanHostSide(cellIds, encodedCanary)`: `docker inspect` of workload and sidecar, `docker logs` of server and sidecars, matched inside dind by a script receiving the encoded canary; returns booleans.
  - A logger that drops every field and never prints values.
- `packages/sandbox/src/providers/opensandbox-it/evidence.ts` + `evidence.test.ts`: pure `buildConformanceEvidence({ profileId, allowlist, checks, measuredAt, platformSha, artifactDigest })`. Throws if any check failed or `allowlist` is empty. Returns rows for `insertProfileEvidenceRows` (no `expiresAt`): `egress: "allowlist"`, `egress_allowlist: allowlist`, `metadata_blocked: true`, `peer_isolated: true`, `teardown_verified: true`, `secret_brokering: true`, `dns_closed: false`, `provider_creds_in_guest: false`, `provider_endpoints_reachable: false`, each `source: "conformance"`, `result: { value, checks: [names] }`. `platformSha` = git HEAD; `artifactDigest` = sha256 of the results JSON. `allowlist` comes from `OPENSANDBOX_IT_PROFILE_ALLOWLIST` (comma list); S4 decides the production list, the IT default is the hosts it measured.
- `packages/shared/src/model/cell-egress-guard.test.ts` (one added case): rows shaped like the builder's (a literal fixture, since shared cannot import sandbox) go through `profileRecordForPolicy` with `configuration.egress_mode: "enforce"`, and `assertCellEgressEnforced` passes; the same rows with `egress_allowlist: []` refuse `allowlist_empty`.
- `packages/sandbox/src/providers/opensandbox-cell.integration.test.ts`: `describe(..., { skip: process.env.OPENSANDBOX_IT !== "1" })`. `beforeAll` runs `up.sh` unless `OPENSANDBOX_IT_REUSE=1`; `afterAll` runs `down.sh` unless `OPENSANDBOX_IT_KEEP=1`. Every stepKey is `osbit-<scenario>-<random>`. Real `fetch`, a timer `sleep`, `Date.now`.
- Guest image `python:3.12-slim` by digest, entrypoint `["sleep","infinity"]`. The self-check argv is a Python probe that does `urllib.request.urlopen("https://example.org/", timeout=5)`: any response → exit 0; every exception (resolver, connect, TLS, timeout) → exit 3; the whole body wrapped so no path exits 1.

### Policies (hardcoded rendered JSON)

- `P_ONE`: `{defaultAction:"deny", egress:[{action:"allow",target:"httpbin.org"},{action:"deny",ports:[80]}]}`.
- `P_CRED`: allows `httpbin.org` and `api.anthropic.com`, then `{deny,ports:[80]}`.
- `P_WILD`: allows `*.github.com` and `github.com`, then `{deny,ports:[80]}`.
- `P_101`: 100 allows (`h000.httpbin.org` … `h099.httpbin.org`, with `httpbin.org` as one of them) plus `{deny,ports:[80]}`.
- Vault (`P_CRED` cells): `{name:"probe", hosts:["httpbin.org"], paths:["/bearer"], auth:"bearer", credential: CANARY_A}`, `{name:"model", hosts:["api.anthropic.com"], auth:"bearer", credential: CANARY_B}`. `CANARY_A` stands in for the broker bearer, `CANARY_B` for the model token.

### Scenarios (each an `it`, each an assertion)

1. **AC-3, enforcement (`P_ONE`).** `https://httpbin.org/get` is 200 (this is the proof; a :443 TCP connect cannot tell enforced from open under the proxy). `httpbin.org:80` TCP is refused. `example.org` DNS is NXDOMAIN. example.org's IP (resolved on the host, in argv): `tls_ip` on :443 fails, TCP :80 times out. DoT `1.1.1.1:853` TCP times out; DoH-by-IP `https://1.1.1.1/dns-query` fails. `169.254.169.254:80` times out (`metadata_blocked`). The server's API from the guest (dind gateway `:8090`) times out (`provider_endpoints_reachable: false`). This combination (proxy on plus these probes) is measured here for the first time.
2. **Live API proofs (`P_ONE`).** `exec(["sh","-c","exit 7"])` → `exitCode 7`; `exec(["printf","%s|","a b","c'd"])` → `a b|c'd|`; `exec(["pwd"],{cwd:"/tmp"})` → `/tmp`; `sh -c 'head -c 1048576 /dev/urandom > /tmp/f && sha256sum /tmp/f'` then `copyOut("/tmp/f")` hashes equal; `listByTags({stepKey})` is exactly this cell.
3. **Peer isolation.** Two `P_ONE` cells; cell A's TCP to cell B's IP on :44772 and :80 times out (`peer_isolated`).
4. **Wildcard and 101 rules.** `P_WILD`: `https://github.com` and `https://api.github.com` are 200-class; `https://gitlab.com` fails. `P_101`: create succeeds and `https://httpbin.org/get` is 200. A refusal fails the `it` and blocks evidence: the S1 renderer can emit 101 rules.
5. **AC-6, canary (`P_CRED`).** `canary_scan` with base64 `CANARY_A` and `CANARY_B` in argv: neither appears in any guest `/proc/*/environ` or `/proc/*/cmdline`, and no env var name matches `/OPEN.?SANDBOX|EGRESS|VAULT/i` (`provider_creds_in_guest: false`). `scanHostSide`: neither in `docker inspect` of workload or sidecar, nor in server or sidecar logs.
6. **AC-5, revoke and teardown (`P_CRED`).** Before revoke, `https://httpbin.org/bearer` sent with **no** Authorization header is 200 (the sidecar adds the header; spike 058 measured add-when-absent only for basic auth, so this is a first measurement for bearer). After `revoke`: it is 401, and `https://api.anthropic.com/v1/models` is 401 (recorded). After `quarantine`: `https://httpbin.org/get` fails and `tls_ip` to the IP learned before fails. `delete` → `"deleted"`, again → `"gone"`. A second cell goes through `teardown()` only; `settledSnapshot` returns to the snapshot taken before both cells within 30 s (`teardown_verified`, `secret_brokering`).
7. **AC-8, negative control.** Runs after 6's snapshot. `rawApi` creates a sandbox with **no** `networkPolicy`; example.org is reached on 4/4 (DNS, https by name, TCP :80, `tls_ip` :443). Its netns leak is recorded as a note.
8. **Evidence.** Only if 1 to 7 passed: `buildConformanceEvidence` → `$OPENSANDBOX_IT_STATE/opensandbox-runc-conformance.json` (rows plus the results). The test asserts it parses and every row is `source: "conformance"`.

Cells are torn down in `finally` through the adapter.

## Validate cycle 2 (PASS_WITH_WARNINGS) — binding adjustments

These override the sections above where they differ.

1. **Guard fixture shape.** The shared case lives in `packages/shared/src/model/execution-profiles.test.ts` (it already calls `profileRecordForPolicy`, `:127`, `:159`). The fixture uses the **database row** types (`ExecutionProfile`, `ProfileEvidence`, `packages/shared/src/db/types.ts:642-643`): each evidence row carries `id`, `expiresAt = measuredAt + 30 days`, `createdAt`, `artifactDigest`, `platformSha`; the profile carries `id`, `provider`, `tier`, `configuration: { egress_mode: "enforce" }`, `configHash`, `createdAt`, `updatedAt`. Without `expiresAt`, `earliest()` throws a RangeError before the guard runs. Phase P1's third file is therefore `execution-profiles.test.ts`, not `cell-egress-guard.test.ts`.
2. **`provider_endpoints_reachable: false`** rests on two checks in scenario 1: the server API at the guest's default gateway (read from `/proc/net/route`, never hardcoded) on :8090 is blocked; and the sidecar's `http://127.0.0.1:18080/policy` and `/credential-vault` refuse the guest (401, 403 or failure). `/healthz` answering is recorded, not failed.
3. **Remaining policy reasons, by design.** With these rows, `cell.rego` still emits `secrets_exfiltrable_by_dns` for any cell with secrets (`dns_closed: false`, `:102-105`) and `egress_host_not_allowed:<h>` for hosts outside the measured allowlist (`:84-87`); the managed tier adds its data-class, repo, lane and legal reasons. S4 owns closing DNS or accepting that reason; this slice measures, it does not decide.
4. **Self-check probe:** catch `Exception` only, and call `sys.exit` outside the `try`, so a reachable host exits 0. The scenario-7 no-policy sandbox runs the same probe and expects exit 0 (live control).
5. **Blocked, not "times out".** TCP and `tls_ip` checks assert `ok === false` and record the error kind (nft may reject or drop).
6. **Env-name check** returns the matching **names** (never values) so a red result is diagnosable.
7. **`P_101`** is exactly `h000.httpbin.org` … `h098.httpbin.org` plus `httpbin.org` (100 allows) plus `{deny, ports:[80]}` = 101 rules.
8. **Peer IP** is read with `dind(["docker","inspect",...])` on cell B's sidecar container (workloads share the sidecar's netns).
