Context frame

  • Use case under test: a PR review run on the Linux box keeps git access to its own checkout while holding no GitHub credential.
  • Defect fixed: the credential strip for review runs removed the whole GIT_CONFIG_* group, including the worker's safe.directory entry. In agent-uid mode git then refused the checkout ("dubious ownership"), and the review agent had no diff to read.
  • Reproduction path: push a commit to a PR on a monitored repo → the platform dispatches a review run → the worker clones as automata and spawns the agent as automata-agent → the agent reads the diff → the platform posts one review.
  • Prior UAT records: none in docs/uat/ reached the re-run threshold for these keys, paths and terms.
  • Criteria source: the epic roadmap's Phase 1 success criteria and the PR #229 body. This project tracks work in GitHub and the repo's planning files, not Jira, so there is no ticket to bind.

Findings

Low

Commit title points at the wrong number

The squash commit is titled "…(#228) (#229)". #228 is the ticket-comment truncation PR. Anyone following the reference lands on unrelated work. Fix going forward: reference the PR or a real issue; history is left as is.

Low

Two copies of the daemon bundle on the box

The worker spawns the /opt build output because WORKER_DAEMON_DIST is unset; run-worker.sh also stages an identical copy under /usr/local/automata/daemon. Today both match (same sha256). If they ever diverge, debugging the wrong one is easy. Worth one line in the runbook.

Info

The worker log does not name a run's lane

The validator could not tell review runs from other runs in the box journal. This run closed the gap by matching each run to the formal review it produced. Logging the lane per run would make the next UAT a single grep.

Info

Carried into later phases from the Phase 2 spike

Runs that use sub-agents emit two final results, and a lead that quotes a sub-agent can make the sub-agent's verdict block the last one the parser sees. Neither affects Phase 1. Both are now success criteria of Phases 5 and 6.
